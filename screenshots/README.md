# SignBridge AI Screenshots

This folder is designated for genuine device screenshots of the running SignBridge AI Android application.

### Recommended Screenshots:
1. `home_screen.png` – Home Screen showing the manual "Start Listening" button, active language card, stats, and accessibility tips.
2. `live_captions.png` – Live Captions screen showing recognized speech bubbles, volume level meter, tentative transcription, and Quick Reply TTS.
3. `country_selection.png` – Country & Language selection modal showing 30+ supported worldwide countries and regional filters.
4. `saved_history.png` – Conversation History list showing SQLite-stored sessions, word counts, and search filter.
5. `settings_screen.png` – Accessibility Settings showing theme toggles, font size options, and microphone status diagnostics.

*To capture screenshots directly from your physical device: Use **Power + Volume Down** on Android, or use **Logcat / Screen Capture** in Android Studio.*
